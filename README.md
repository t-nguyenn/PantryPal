# PantryPal

PantryPal is a Flutter application that helps users organize pantry items, track expiration dates, and discover recipe ideas based on available ingredients.

## Features

- 🥫 Pantry inventory management
- ⏰ Expiration date tracking
- 🍽️ Recipe recommendations
- 🔥 Firebase Authentication
- ☁️ Cloud Firestore integration
- 🎨 Material 3 user interface

## Technologies

- Flutter 3.44
- Dart
- Firebase Authentication
- Cloud Firestore

## Getting Started

```bash
flutter pub get
flutter run
```
